Open and closed

A set A is open in a space S if every point of A has a ball around it — intersected with S — that stays inside A. Which space you are asked about does all the work here.

Draw a set in ℝ²₊ that is neither open nor closed

You need one point that fails openness and one limit point that fails closedness. A half-open box does both at once.

AnswerA worked example

B = {(x,y) ∈ ℝ²₊ : x < 2, 0 ≤ y ≤ 2}.

Not open in ℝ²₊: take the point (1, 2). Every relative ball around it contains points with y > 2, which are in ℝ²₊ but not in B.

Not closed in ℝ²₊: the sequence (2 − 1/n, 1) lies in B and converges to (2, 1), which is not in B. A closed set contains all its limits.

Draw a set that is open in ℝ²₊ but closed in ℝ²

Try a few candidates before opening this one. The answer is shorter than you expect.

HintWhat does "closed in ℝ²" buy you?

If S ⊆ ℝ²₊ is closed in ℝ², then it is also closed in ℝ²₊. So you are hunting for a set that is open and closed in ℝ²₊ at the same time.

Answerℝ²₊ itself, and nothing else

The whole space is always open in itself, and ℝ²₊ = {x ≥ 0, y ≥ 0} is closed in ℝ² because both inequalities are weak. So it works.

It is also the only non-empty answer. By the hint, any such set is both open and closed in ℝ²₊. The quarter-plane is connected — you can walk between any two of its points without leaving it — and a connected space has exactly two clopen subsets, the empty set and the whole thing.

Convex

The economics behind the table: an upper contour set {u(x,y) ≥ k} is convex for every k exactly when u is quasiconcave — which is what "the consumer likes averages at least as much as extremes" means. Three of these four utilities pass. x² + y² fails, and the chord tool shows you where.

Solve the systems

Each system is two lines in ℝ². The determinant tells you which of the three pictures you are in before you solve anything.

How the determinant decides

For ax + by = e and cx + dy = f, write D = ad − bc.

  • D ≠ 0: the lines cross once. Unique solution, x = (ed − bf)/D, y = (af − ec)/D.
  • D = 0 and the constants scale the same way: the two equations are the same line. Infinitely many solutions.
  • D = 0 and they do not: parallel lines that never meet. No solution.

Check the question's last line. The problem set says some systems have multiple solutions. Work the four determinants: you get −1, 0, 17 and −16, so three systems have exactly one solution and one has none. None of the four has infinitely many.

Change the second system's right-hand side from 5 to 14 and 6x + 8y = 14 becomes twice 3x + 4y = 7 — one line, infinitely many solutions. The button on that card does it, so you can see all three pictures.
