Matrices, inverses and what survives them

Every number on this page is computed from the matrices as written — products and inverses exactly, in fractions; eigenvalues numerically. Work each part by hand first, then use the lab to check.

Solve PS1's systems by inverting the matrix

Write each system as Mx = r. When M⁻¹ exists, x = M⁻¹r — one formula, no elimination. When it does not, find out what goes wrong.

The 2×2 inverse, once

For M = [[a, b], [c, d]] with D = ad − bc ≠ 0,

M−1 = (1/D) · [[ d, −b ], [ −c, a ]]

Swap the diagonal, negate the off-diagonal, divide by the determinant. Everything about solvability sits in that division: if D = 0 there is nothing to divide by, and the matrix has no inverse.

Why "no inverse" and "no unique solution" are the same statement. D = 0 means the two rows of M are proportional, so the two equations describe parallel lines. Either they coincide (infinitely many solutions) or they do not (none). In both cases no single matrix can undo M, because M has squashed the plane onto a line and that cannot be reversed.

Part aVerify v, and find the rest

Av computes to the zero vector, so v is in the null space. Press the button to watch both rows land on zero.

Are there others? Yes — infinitely many, and all of them are multiples of v. Row-reduce A: the two rows are not proportional, so the rank is 2, and the rank–nullity theorem gives nullity = 3 − 2 = 1. A one-dimensional null space is a line through the origin, so {t·v : t ∈ ℝ} is all of it.

Try v = (−1/8, −13/4, 2) in the boxes: still zero.

Part bOnly 0 on the left

The left null space is {w ∈ ℝ² : wA = 0}. Writing it out, wA = 0 means three equations:

2w₁ − 4w₂ = 0  |  3w₁ + 2w₂ = 0  |  5w₁ + 3w₂ = 0

The first gives w₁ = 2w₂. Substituting into the second: 6w₂ + 2w₂ = 8w₂ = 0, so w₂ = 0 and then w₁ = 0. Only the zero vector survives — the space is trivial.

Part cWhat that tells you

Rank 2. The left null space of A is the null space of Aᵀ, and it is trivial, so Aᵀ has nullity 0 and rank 2. Rank is the same for a matrix and its transpose.

Column space = all of ℝ². It is a subspace of ℝ² of dimension 2, so it is everything. In other words Ax = b has a solution for every b ∈ ℝ² — and never a unique one, since you can always add any multiple of v.

Row space. A 2-dimensional plane inside ℝ³, spanned by (2,3,5) and (−4,2,3). It is exactly the set of vectors perpendicular to v: row space and null space are orthogonal complements, and 2 + 1 = 3 dimensions in total.

Does PQ = QP?

No, not in general — and the lab makes that concrete. Put A on the left and B on the right, note the answer, then press Swap the order. AB scales the columns of A by 1, 2, 3; BA scales its rows. Different operations, different matrices.

Some pairs do commute. Two diagonal matrices always do, and so does any matrix with itself or with the identity. In this collection, try B against B.

Why PᵀQᵀ = (QP)ᵀ

Entry (i, j) of (QP)ᵀ is entry (j, i) of QP, which is row j of Q dotted with column i of P. Entry (i, j) of PᵀQᵀ is row i of Pᵀ — that is, column i of P — dotted with column j of Qᵀ, which is row j of Q. Same two vectors, same dot product. The order reverses because transposing turns rows into columns, and the matrix that was reached first by rows must now be reached last by columns.

Determinants and inverses

The determinant decides whether an inverse exists. Gauss–Jordan then builds it, one row operation at a time, in exact fractions.

All five determinants

Read C before you compute it. Its three rows are identical. Any matrix with two equal rows has determinant zero, because swapping those rows must flip the sign while leaving the matrix unchanged — and only zero equals its own negative. No elimination needed.

Eigenvalues, eigenvectors, definiteness

An eigenvector is a direction the matrix does not turn; the eigenvalue is how much it stretches that direction. Definiteness asks the different question of whether xᵀMx keeps one sign.

The summary

Two cautions the question hides. First, A's characteristic polynomial is λ³ − 6λ² − 9λ − 6 = 0, which has one real root near 7.34 and a complex pair. There is no hand calculation that produces it, so use the numerical value and say so.

Second, positive and negative definiteness are properties of a symmetric matrix. A and C are not symmetric, so test them through the symmetric part (M + Mᵀ)/2, which gives the same quadratic form xᵀMx. The lab does this and shows you both.
