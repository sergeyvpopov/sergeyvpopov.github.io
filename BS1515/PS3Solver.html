Limits

A limit L means: name any tolerance ε > 0, and from some point on, every term sits within ε of L. Pick a sequence, set ε, and the lab finds the smallest N that works.

Continuous functions preserve convergence

If aₙ → a and f is continuous at a, then f(aₙ) → f(a). The proof is two definitions laid end to end.

ProofChain the two ε–δ statements

Fix ε > 0. Continuity at a hands you a δ > 0 such that |x − a| < δ implies |f(x) − f(a)| < ε.

Now feed that δ back into the convergence of aₙ, treating it as the tolerance: there is an N with |aₙ − a| < δ for every n ≥ N.

Combine: for n ≥ N we get |f(aₙ) − f(a)| < ε. That is exactly the statement f(aₙ) → f(a).

The direction matters. You choose ε for the output, continuity converts it into a δ for the input, and convergence of the sequence then delivers that δ. Writing it the other way round proves nothing.

Where completeness enters. Both monotone-convergence proofs rest on a supremum or infimum existing, and that is a property of ℝ, not of ℚ. The same argument inside ℚ fails: the decreasing bounded rational sequence 1, 1.4, 1.41, 1.414, … has no rational limit.

Derivative rules

The three rules to prove

Sum(f + g)′ = f′ + g′

Write the difference quotient and split it:

[f(x+h)+g(x+h) − f(x)−g(x)] / h  =  [f(x+h)−f(x)]/h  +  [g(x+h)−g(x)]/h

Both pieces converge, because f and g are assumed differentiable. The limit of a sum of two convergent things is the sum of their limits, so the whole quotient tends to f′(x) + g′(x).

No trick here, which is the point: the split is legitimate only once you know each half converges separately.

Product(fg)′ = f′g + g′f

The obstacle is that f(x+h)g(x+h) − f(x)g(x) does not split. The trick is to add and subtract a bridging term:

f(x+h)g(x+h) − f(x+h)g(x) + f(x+h)g(x) − f(x)g(x)

Group and divide by h:

f(x+h) · [g(x+h)−g(x)]/h  +  g(x) · [f(x+h)−f(x)]/h

As h → 0 the two quotients become g′(x) and f′(x). The leading factor f(x+h) tends to f(x) — and that step needs f to be continuous at x, which differentiability guarantees. Result: f(x)g′(x) + g(x)f′(x).

Chain(f ∘ g)′ = f′(g(x))·g′(x)

The one-line version multiplies and divides by g(x+h) − g(x):

[f(g(x+h))−f(g(x))] / [g(x+h)−g(x)]  ×  [g(x+h)−g(x)] / h

and lets h → 0. The second factor tends to g′(x); the first is a difference quotient for f at g(x) with step k = g(x+h) − g(x), which tends to 0, so it tends to f′(g(x)).

The gap. If g is locally constant, k = 0 and you have divided by zero. Patch it by defining

φ(k) = [f(u+k) − f(u)] / k for k ≠ 0,   φ(0) = f′(u),   u = g(x)

Then φ is continuous at 0 by the definition of f′(u), and the identity [f(g(x+h)) − f(g(x))]/h = φ(k)·(k/h) now holds for every small h, including those with k = 0. Take limits and the chain rule follows with no division by zero anywhere.

Four results to establish

Power(xᴺ)′ = Nxᴺ⁻¹ for N ∈ ℕ

Induction, with the product rule doing the work.

Base. N = 1: the difference quotient is [(x+h) − x]/h = 1, and 1·x⁰ = 1. ✓

Step. Assume (xᴺ)′ = Nxᴺ⁻¹ for some N ≥ 1. Then

(xN+1)′ = (x · xN)′ = 1·xN + x·NxN−1 = xN + NxN = (N+1)xN

which is the claim at N + 1. Note the inductive hypothesis must be stated for some N, not all of them — assuming it for all N assumes what you are proving.

Root(x^½)′ = ½x^−½

The induction above does not reach fractional powers, so go back to the quotient and rationalise the numerator:

[√(x+h) − √x]/h  ×  [√(x+h) + √x]/[√(x+h) + √x]  =  (x+h−x) / (h[√(x+h)+√x])  =  1/[√(x+h)+√x]

The h has cancelled, so the limit is immediate: 1/(2√x) = ½x^−½, valid for x > 0.

Reciprocal(1/f)′ = −f′/f²

Fastest route: differentiate the identity f(x) · (1/f(x)) = 1 with the product rule. The right side is constant, so its derivative is zero:

f′(x)·(1/f(x)) + f(x)·(1/f)′(x) = 0

Solve for the unknown: (1/f)′ = −f′/f², wherever f(x) ≠ 0.

This assumes 1/f is differentiable. To avoid assuming that, use the chain rule on u ↦ 1/u instead, after proving (1/u)′ = −1/u² from the difference quotient directly.

Log(ln x)′ = 1/x, given (eˣ)′ = eˣ

Start from the identity that defines the logarithm: e^(ln x) = x for x > 0.

Differentiate both sides. The left needs the chain rule with outer function eᵘ and inner function ln x:

eln x · (ln x)′ = 1  ⟹  x · (ln x)′ = 1  ⟹  (ln x)′ = 1/x

The whole proof is one application of the chain rule to a tautology. The same move gives the derivative of any inverse function.
